# 2026-10-22 侧栏底部直角阴影修复

## 任务来源

Timmy 反馈：亮色背景下，左侧菜单栏底部有一道直角形状的阴影，看起来不正常，要求去掉。

## 根因

不是阴影本身的问题，是**外层裁剪把圆角投影切成了直角**：

- `.sidebar`（`AppSidebar.svelte`）是圆角卡片：`border-radius: 14px`，带投影 `box-shadow: inset 0 1px 0 var(--glass-highlight), var(--glass-shadow)`（亮色下 `--glass-shadow: 0 10px 30px rgba(0, 0, 0, 0.12)`）。
- 外层 `.side-shell`（`+page.svelte`）为做侧栏收起动画有 `overflow: hidden`，但**没有 `border-radius`**——裁剪边界是矩形。
- 圆角卡片的投影本应沿 14px 圆角向外扩散；被矩形边界一裁，底部两角的阴影被切成直角，即用户看到的异常阴影。

`.side-shell` 尺寸与 `.sidebar` 完全一致（同宽同高），所以投影中落在壳内、但位于圆角外侧的部分被裁成直角边。

## 修复

`apps/desktop/src/routes/+page.svelte` 的 `.side-shell` 增加与 `.sidebar` 相同的 `border-radius: 14px`，并加注释说明原因。裁剪形状与卡片圆角一致后，投影沿圆角走，直角消失。

只改这一处 CSS；未动 `.sidebar` 的投影、尺寸、动画，也未删阴影（阴影本身是"唯一浮起圆角卡片"设计的一部分，问题只在被裁成直角）。
