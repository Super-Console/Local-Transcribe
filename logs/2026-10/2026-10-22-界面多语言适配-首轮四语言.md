# 界面多语言适配（首轮：英/西/法/德）— 2026-10-22

执行 AI：OpenCode（MiMo V2.6 Flash）。改动仅限前端 Svelte 层；Rust 后端、CLI、MCP 输出不在本轮范围。

## 目标

GUI 界面支持多语言，第一轮覆盖：简体中文（源语言）、English、Español、Français、Deutsch。

## 方案：手写轻量 i18n（零新增依赖）

决定不引入 svelte-i18n（可能的 Svelte 5/Vite 8 兼容风险 + formatjs 运行时体积），改为项目内手写：

- `src/lib/i18n/messages/types.ts`：`Message = string | Record<string, string>`（复数对象按 `Intl.PluralRules` 类别取值，缺类别回退 `other`）。
- `src/lib/i18n/messages/zh.ts`：中文源，99 个 key（扁平点分命名），导出 `MessageKey`。
- `en.ts / es.ts / fr.ts / de.ts`：类型均为 `Record<MessageKey, Message>` —— **key 对齐由 TypeScript 编译期强制**（缺 key / 多 key 都会 `npm run check` 报错）。
- `src/lib/i18n.svelte.ts`：Svelte 5 runes 状态（`.svelte.ts` 才能用 runes，与 theme.svelte.ts 同一模式）：
  - 偏好持久化键 `lt.locale.v1`：`system | zh-CN | en | es | fr | de`，默认 `system`。
  - 跟随系统：启动时读 `navigator.languages`，zh/en/es/fr/de 前缀匹配，其余回退 `en`（macOS 改系统语言需重启应用才生效）。
  - `t(key, params?)`：单函数同时处理插值 `{name}` 与复数（`Intl.PluralRules`）；缺 key 回退中文。
  - `formatDayLabel` / `formatClock`：日期时间走 `Intl.DateTimeFormat`（历史页原来硬编码 `toLocaleTimeString("zh-CN", …)`）。
  - 同步 `document.documentElement.lang`。
- 设置页新增「界面语言」行：原生 `<select>`，选项 = 跟随系统 + 五语言母语名（语言名不随界面语言变化，业界惯例）。
