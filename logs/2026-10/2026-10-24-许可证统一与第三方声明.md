# 许可证统一与第三方声明（2026-10-24）

依据：《许可证统一与第三方声明任务书 V1.0》。代码采用 MIT；本轮只改元数据、文档、声明与打包资源，不改依赖版本、不改模型清单、不写未发生的授权。

## 1. 元数据

- 5 个 crate（core / service / cli / mcp / lan-compute）的 `license` 从 `UNLICENSED` 改为 `MIT`。
- 根 `Cargo.toml` 新增 `[workspace.package] license = "MIT"`。
- `apps/desktop/src-tauri/tauri.conf.json` 新增 `bundle.copyright = "Copyright © 2026 TimmySheep"`。
- `LICENSE` 与 `apps/desktop/package.json` 维持 MIT。
- `grep -rn "UNLICENSED" --include=Cargo.toml .` 为空。

## 2. README（双语）

`README.md` / `README.zh-CN.md` 的 License 小节写明：代码 MIT；"Local Transcribe" 名称与应用图标不在授权范围内；第三方组件保留各自许可证并指向 `THIRD-PARTY-NOTICES.md`。其它段落未改。

## 3. `THIRD-PARTY-NOTICES.md`

- 用 `cargo metadata --format-version 1 --all-features` 解析出 workspace 成员的 normal/build 依赖闭包（排除仅 dev 的边），加上 `apps/desktop/package.json` 的运行时 `dependencies`。
- 生成脚本：`scripts/generate-third-party-notices.py`（只用标准库，未安装任何全局工具；可重复运行）。
- 结果：605 个包（603 个 Rust、2 个前端），按 MIT / Apache-2.0 / MPL-2.0 / BSD / 双许可与其他分组，组内按名称排序。
- 开头单独点名：
  - **sherpa-onnx**：Apache-2.0，经 `sherpa-onnx-sys` 静态链接运行库；
  - **symphonia**：MPL-2.0（文件级 copyleft），本项目未修改其源码；若将来修改，被修改文件需按 MPL-2.0 公开。

## 4. 带进安装包与界面入口

- `tauri.conf.json` 的 `bundle.resources`：`../../../LICENSE → LICENSE`、`../../../THIRD-PARTY-NOTICES.md → THIRD-PARTY-NOTICES.md`。
- 新增 Tauri 命令 `third_party_notices_path`：优先返回 `Contents/Resources/THIRD-PARTY-NOTICES.md`，开发运行回落到仓库根目录。
- 设置页「关于」组新增「第三方声明」一行与「打开声明」按钮（五语言 key：`settings.thirdParty` / `settings.thirdPartyDesc` / `settings.openNotices`）。
- 打包实测（`npm run tauri -- build --bundles app --no-sign`，release 2m12s）：
  - `target/release/bundle/macos/Local Transcribe.app/Contents/Resources/` 下同时存在 `LICENSE`（1,067 B）与 `THIRD-PARTY-NOTICES.md`（49,798 B）；
  - 按项目既有做法 ad-hoc 签名 sidecar 与 .app 后，`codesign --verify --deep --strict` 通过。
- 本次没有重新发布：已发布的 1.2.0-beta.1 资产早于本轮改动，**安装包内不含这两份声明**；按收尾任务书的约束不覆盖已发布资产，下一版打包会自动带上。发布页也还没有附 `THIRD-PARTY-NOTICES.md`，留给下一次发布处理。
