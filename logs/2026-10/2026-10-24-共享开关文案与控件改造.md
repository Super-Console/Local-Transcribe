# 共享开关文案与控件改造（2026-10-24）

依据：《共享开关文案与控件改造任务书 V1.0》。只改「允许其他设备使用本机算力」这一个控件、它的文案与一条提示；未改启停逻辑、知情同意、端口/网卡表单，未评价观感、未截图。

## 改动

- **状态点**：把 `AppToolbar` 里的点样式抽成 `apps/desktop/src/app.css` 的共享类 `.status-dot`（7×7、50%、关 `#cbc5b7`、深色 `#5a5a60`、开 `var(--green)`）。`AppToolbar`（顶栏模型点、菜单项点）与 `LanView` 共用这一个类，各自组件里不再保留 `.dot` / `.item-dot` 样式副本。
- **LanView 共享区块**：标题左侧加 `<span class="status-dot" class:on={host.running} aria-hidden="true">`；标题与点在同一 flex 行，间距 8px。
- **按钮**：去掉 `role="switch"` 与 `aria-checked`，改为普通动作按钮：
  - 文案只写动作：`开启共享` / `关闭共享`；
  - `aria-label` 为「标题, 状态词」（同时含"允许其他设备使用本机算力"和已开启/已关闭），`title` 显示状态词；
  - 切换中 `disabled`、`aria-busy="true"`，文案为「正在开启…」/「正在关闭…」（按切换前的 `host.running` 判断方向）；
  - 失败仍走原有 `host.notice`。
- **文案**：五语言新增 `lan.hostActionOn/Off`、`lan.hostStateOn/Off`、`lan.hostChangingOn/Off`，删除 `lan.hostOn/hostOff/hostChanging`；新值不含「点击」/`Turn on`/`Turn off`。
- **内存提示**：删除 `LanView.svelte` 里的 `lan.memoryHint` 一行和五语言的该 key；原因（两个进程峰值相加不等于同一时刻）保留在 README/docs，不进入界面。

## 断言（`apps/desktop/tests/sharing-switch.test.mjs`，5 条）

1. 五语言不再有四个旧 key；六个新 key 都存在且值不含 `点击` / `Turn on` / `Turn off`。
2. `app.css` 的 `.status-dot` 为 7×7、50%、`#cbc5b7`，`.on` 为 `var(--green)`，深色为 `#5a5a60`；`LanView` 与 `AppToolbar` 都用 `status-dot`，`AppToolbar` 不再有本地 `.dot` / `.item-dot`。
3. 点有 `aria-hidden="true"`；按钮没有 `role="switch"` / `aria-checked`；`aria-label` 同时包含标题与状态词。
4. 按钮文案 `hostActionOff : hostActionOn`；切换中文案 `hostChangingOff : hostChangingOn`；`aria-busy` 与 `disabled` 条件正确。
5. 共享区块内不再出现「内存」或 `GB`（`LanView` 全文无 `内存`/`memoryHint`，区块切片无 `GB`）。
