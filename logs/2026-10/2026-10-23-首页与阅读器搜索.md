# 首页全文搜索 + 阅读器内搜索（2026-10-23）

执行 AI：OpenCode（DeepSeek V4.1 Flash）。

## 需求

参考 TranscribeX：主页要有搜索（文件名 + 转写正文都能搜），转写稿里也要有搜索。并更新文档、推送到 GitHub。

## 实现

- 后端新增命令 `search_history(query)`：读取本地 `transcripts/*.json`，对 `sourceFileName` 与 `text` 做大小写不敏感匹配；命中正文时返回命中位置前后约 30/110 字的片段（按字符截取，不破坏 UTF-8；首尾补省略号）。新增 `match_snippet` 及 2 个单元测试（中心截取 + 无命中回退），全部通过。
- 顶栏新增搜索框（参考设计的圆角浅底 + 放大镜 + 清除按钮），输入防抖 220ms；搜索时首页改为「找到 N 条」结果卡片，卡片内展示命中片段（浅陶土底），空结果与加载中都有明确状态。
- 阅读器（Reader）新增本稿搜索：过滤命中段落、陶土色 `<mark>` 高亮、显示「N 处匹配 / 没有匹配」；搜索时暂停自动跟随滚动。
- 历史详情原来用的是自绘阅读区，改为复用 Reader 组件（新增 `initialFollow` 参数，详情从顶部开始、不自动滚到底），因此详情页同样获得稿内搜索。
- 搜索输入框关闭自动补全/拼写（`autocomplete/autocorrect/spellcheck`），避免 macOS 建议弹窗。
- i18n：搜索与稿内搜索文案补齐五种语言。

## 验证

- `npm run check` 0/0；`cargo test` 全绿（含新增搜索片段测试）。
- CUA 实测：搜 `demo` → 找到 6 条（文件名命中）；搜 `the` → 找到 7 条（正文命中，片段可见）；无结果显示空状态；打开记录后稿内搜 `the` → 「9 处匹配」+ 高亮。
