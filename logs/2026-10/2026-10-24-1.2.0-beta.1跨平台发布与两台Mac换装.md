## 4. Windows 真机验证（Tims-Gaming-PC，100.94.223.63）

### 4.2 MSI 安装

- 从 CI artifact 取 MSI 安装，`MSIEXEC_EXIT=0`，注册版本 1.1.0.2 → 1.2.0.1。
- 安装路径 `C:\Program Files\Local Transcribe\`；`local-transcribe-node.exe` SHA-256 与 CI 产物一致（见上表）；node `--help` exit 0。

### 4.3 GUI 启动：SSH session 0 限制 → 计划任务落 session 1

- 从 SSH（session 0）直接启动应用会因窗口站隔离崩溃（WebView2 `0x80070578 无效的窗口句柄`，事件日志 1000/1001 ×3）；计划任务首次注册时 `/tr` 路径在空格处被拆开（`LastTaskResult=0x80070002`），改用 `New-ScheduledTaskAction -Execute`（单字符串路径）修正。
- 修正后以计划任务（Interactive principal，用户 TGP）在 **session 1** 启动成功：`voice-to-text-desktop` PID 13992 + WebView2 子进程，无新崩溃事件。判定：session 0 崩溃属 Windows/SSH 固有限制，非应用缺陷。

### 4.4 「顶部无菜单栏」运行时验证（session 1 内枚举）

检查脚本本身也经计划任务跑在 session 1（绕开窗口站隔离），对该进程枚举全部窗口：

```
WINDOWS_FOUND=6
主窗口  handle=0x7006A visible=True  has_menubar=False title=[Local Transcribe]
其余 5 个（隐藏/IME 窗口）has_menubar=False
WINDOWS_WITH_MENUBAR=0
```

**结论：运行时确认无菜单栏**（`GetMenu(hwnd)` 全部为 NULL），与编译期 cfg 断言互证。窗口标题正确。

### 4.5 共享与 7878（开启共享后归节点）

- 应用按 `lan-settings.json` 自动恢复共享，拉起 `local-transcribe-node`（session 1，PID 12156）：
  - `Get-NetTCPConnection -LocalPort 7878`：`LISTEN=0.0.0.0:7878 PID=12156 PROC=local-transcribe-node` ✅
  - 节点日志：`node "Local Transcribe" listening on 0.0.0.0:7878 (compute: on)`，mDNS 已宣告 `192.168.1.200:7878`。
- 此前先用直接运行安装目录节点（`--compute off`）验证过端口归属与 HTTP 响应，收尾已清理。

### 4.6 验证过程中发现并处理的三件事

1. **手写 `lan-settings.json` 的 serde 陷阱**：`LanMode` 标注 `rename_all = "snake_case"`，合法值是 `local_only`/`prefer_lan`；我最初手写的 `"LocalOnly"` 反序列化失败导致自动恢复静默跳过。改为 `local_only` 后恢复链路打通。（这是验证操作侧的配置错误，非产品缺陷。）
2. **这台 Windows 当前没有任何模型**，而 GUI 固定以 `--compute on` 拉起节点 → 节点报 `--compute on needs at least one usable model` 即退。按任务书「缺什么自己补」：从 MBP 拷贝最小的 transducer 模型（`sherpa-onnx-x-asr-zipformer-transducer-zh-en-int8-2026-06-03`，168 MB，本地机器间传输非联网下载，4 文件字节数与 MBP 一致）到 `%LOCALAPPDATA%\com.timmy.voicetotextapp\models\`，节点随即正常启动。**模型留在机器上**（属应用正常数据，Timmy 可在应用内删除）。
3. **防火墙入站**：三个配置文件均启用且无 7878 放行规则（10/23 的临时测试规则当时已按计划删除）。从 MBP 经局域网与 Tailscale 访问 Windows:7878 均超时——默认入站拦截所致。任务书 §4 客观项不含跨机访问 Windows，**未添加防火墙规则**（机器级设置不擅动）；该注意事项已写入 release notes。
