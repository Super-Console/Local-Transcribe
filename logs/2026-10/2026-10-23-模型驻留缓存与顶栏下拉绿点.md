# 模型驻留缓存 + 顶栏下拉与绿点 + 字号放大（2026-10-23）

执行 AI：OpenCode（DeepSeek V4.1 Flash）。

## 一、模型驻留（任务书要求落地）

任务书原文约束：同时最多装载一个模型；任务开始按需加载；同模型连续任务复用；切换型号在安全任务边界卸载；**共享队列空闲 120 秒后卸载**；顶部绿点只表示真正驻留内存。

实现（`crates/transcription-core/src/asr.rs`）：
- 新增进程内 `RECOGNIZER_CACHE: Mutex<Option<CachedRecognizer>>`（model id + 目录 + recognizer + last_used）。
- 转写时：命中同模型复用，否则在任务边界创建新 recognizer 替换旧的（旧模型随之卸载）。
- 空闲卸载线程：首次加载后启动，每 5 秒检查，空闲 ≥120 秒释放。
- 导出 `loaded_model_id()` / `idle_unload_seconds()`；Tauri 新增命令 `model_runtime`。
- 验证：新增 ignored 集成测试 `crates/transcription-core/tests/loaded_model.rs`（真实 paraformer 模型 + 合成 1.2s 静音 WAV），断言任务结束后 `loaded_model_id()` 等于该模型 id —— **通过**。

## 二、顶栏模型下拉（AppToolbar）

- 点击「默认模型」不再是跳到模型页，而是展开下拉浮层：
  - 每个模型一行（名称 + 家族 · 体积），当前默认打勾；
  - **行首圆点：绿色 = 真正驻留内存，灰色 = 未加载**（aria/title 提示「已加载到内存」）；
  - 底部「管理模型」跳转模型页；点击遮罩关闭。
- 前端每 2 秒轮询 `model_runtime` 更新绿点。
- 限制（已记录）：绿点反映 **GUI 进程** 的驻留状态；CLI/MCP 任务在服务进程加载，不显示为绿点（服务进程状态尚未进入服务协议）。
