Microsoft documents Windows AF_UNIX filesystem ACL enforcement: https://devblogs.microsoft.com/commandline/af_unix-comes-to-windows/. No secure replacement or cross-user denial has yet been implemented or verified. Do not publish or install 1.7.0.
- MCP flags on an already-running service cannot currently add a process-scoped permission; a check now returns an explicit error rather than silently ignoring them. Full requested semantics remain pending.
