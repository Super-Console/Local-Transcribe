## 1. P0 · 三个阻断级 bug（先修这三个，其余都排在后面）

### 1.1 「首页」「查找」点不动

**现象**：两个胶囊看着正常，点下去没有任何反应，回不去首页。

**定位方法（不许猜）**

1. 打开开发者工具，在「首页」胶囊的中心位置执行：
   `document.elementFromPoint(x, y)`，看返回的是谁
2. 如果不是按钮本身，记下那个元素（很可能是新加的 `.reader-fade` 或某个覆盖层）
3. 逐层检查该元素的 `pointer-events` / `z-index` / `position`

**要求**

- 覆盖层（渐隐带、任何 decorative layer）必须 `pointer-events: none`
- 两个胶囊所在的行必须 `z-index` 高于覆盖层，且自身 `pointer-events: auto`
- 修完必须**真的点一次**：点「首页」回到列表页，点「查找」展开输入条并聚焦
- 加一条测试：模拟点击胶囊 → 期望的回调被调用（不允许只测元素存在）

### 1.2 模型下拉面板透明，正文穿透

**现象**：点开右上角模型选择器，菜单项底下能看见正文文字，条目与正文叠在一起。

**原因方向**：面板没有不透明底，或用了玻璃参数（`backdrop-filter` + 低 alpha）但模糊未生效。

**要求**

- 下拉面板是**内容层**，不许用玻璃。给实心底：
  ```css
  background: var(--panel);            /* #fffefb */
  border: 1px solid var(--hairline);
  border-radius: 12px;
  box-shadow: var(--shadow-panel);
  ```
- 深色用 `--bg` 深色值 + `--hairline`，同样不许半透明
- `z-index` 高于阅读器条与渐隐带；面板内文字不得有任何透明度
- 菜单项 hover 用 `--hover`，选中项用 `--selected`
- 验证：打开下拉后**截图**，面板区域内不得看到任何正文笔画

### 1.3 顶部区域混入正文文字 + 滚动条压到头部行

**现象**（Timmy 截图放大后可见）：顶部同一行里同时出现灰色的 `…ON`（JSON 标签末尾）、一个深色的 `TOP`、以及一条浅灰的滚动条 thumb，三者挤在一起。

**先定位，不许猜**：那是 2 倍放大的局部，肉眼无法判断这几个字符属于谁。要求先取坐标并查：

- `document.elementFromPoint(x, y)` 分别对准 `…ON`、`TOP`、滚动条三处，记录各自命中的元素
- 若 `TOP` 是正文（例如标题或段落被裁切），说明顶部渐隐没有盖到容器最顶端
- 若 `TOP` 是遗留的调试标签，删掉
- 若滚动条 thumb 从容器顶端 y=0 就开始画，说明轨道没有被推到头栏之下

**要求**

1. 顶栏区域（0–40px）内，除顶栏自己的控件外**不得出现任何正文字符**
2. 层级必须是：正文 < 顶部渐隐带 < 顶栏控件；渐隐带要覆盖到容器最顶端，不能只从 y=8 开始
3. 滚动条轨道起点不得进入顶栏区域：给滚动容器 `padding-top`（约 40px）或让轨道从顶栏之下开始
4. 滚动条 thumb 与顶栏文字**不得有任何重叠**（当前 thumb 就压在 `TOP` 与 JSON 之间）
5. 若确实存在调试用文字，立即删除，并检查是否有其它残留

**验收**：同一位置 2 倍放大截图，顶栏那一行只能看到控件与底色——不能有其它字符，也不能有滚动条压在文字上。

## 2. P1 · 圆角统一（消灭直角残留）
**现象**：首页上方、阅读器内容区、以及「查看最新」附近，四个角能看到一点点直角。

**要求**

1. 逐个审计这四处：首页内容区四角、阅读器内容区四角、滚动容器边界、「查看最新」所在的浮层边缘
2. 统一用 `--radius`（12px）；**父容器圆角 + 子容器直角背景** 是最常见的原因，子元素必须 `overflow: hidden` 或用同半径
3. 滚动条轨道不得在圆角之外露直角：轨道背景透明，或让它参与裁剪
4. 「查看最新」若是胶囊，必须是全圆角（999px），不许出现直边
5. **验收方式**：四个角各截一张放大图（≥2 倍），不得出现直角边或色块溢出

## 3. P2 · 胶囊统一

**基准**（沿用《阅读器顶栏胶囊化任务书 V1.0》）：高 30px、`border-radius: 999px`、1px 细边、上沿 1px 高光、`blur(18px) saturate(1.1)`。

### 3.1 导出按钮 TXT / JSON → 次要胶囊

- 由纯文字改为**次要胶囊**：底 `rgba(255,254,251,.66)`、边 `rgba(20,20,19,.05)`
- 图标 12px + 文字 12px，左右内边距 10px，高 30px
- hover 底色升到 .78；不加边框加深
- 两个之间间距 8px

### 3.2 右上三个控件 → 同族

| 控件 | 改法 |
| --- | --- |
| 搜索 | 图标按钮：宽高各 30px、全圆（胶囊的极限形态）、底色 `.66`、hover `.78` |
| 月亮 | 同上，与搜索完全同规格、同底色 |
| 模型选择器 | 文字胶囊：高 30px、左右 12px、底色 `.66`、右侧下拉箭头 12px；宽度自适应，过长时文字省略号截断（**不许**撑破工具栏） |

**判断依据（写清，避免实现时自作主张）**：只有图标、没有文字的按钮保持**正圆**——横向拉成椭圆只会显得空；这不是偷懒，是胶囊族的一致做法。模型选择器有文字，所以是真正的长胶囊。

**统一要求**

- 四个圆点/圆角在视觉上必须像一族：高度一致、底色一致、描边一致
- 深色主题按既有深色参数，不许出现发亮的白斑
- 三处 hover / active / focus 行为一致：hover 底色 +.06、active 内缩 1px、focus 显示 `--accent` 2px 外环

## 4. P3 · 滚动条调细（原生样式，不自绘）

- 首页 `.content` 与阅读器 `.reader-scroll` 都要
- 两套写法都写：
  ```css
  scrollbar-width: thin;
  scrollbar-color: rgba(20,20,19,.18) transparent;
  ```
  ```css
  ::-webkit-scrollbar { width: 8px; height: 8px; }
  ::-webkit-scrollbar-track { background: transparent; }
  ::-webkit-scrollbar-thumb {
    background: rgba(20,20,19,.18);
    border-radius: 4px;
    border: 2px solid transparent;
    background-clip: content-box;
  }
  ```
- 深色：thumb 改 `rgba(255,255,255,.16)`
- **不隐藏滚动条、不自绘指示器、不改滚动逻辑**
- 验证：macOS 与 Windows 各滚一次，都是细而淡的一条、轨道透明、无上下箭头
