## 1. 首页历史卡片：右键删除

**现状**：首页卡片没有任何删除入口，历史只能靠保留策略被动清理。

### 交互

- 卡片上**右键**弹出上下文菜单，只有一项：`删除`（危险色）
- 同时支持键盘：卡片可获得焦点，`Shift+F10` 或 `ContextMenu` 键触发同一菜单
- 不新增常驻的「⋯」按钮（保持卡片干净）
- 菜单点击外部或按 `Esc` 关闭

### 确认

点「删除」后弹确认，文案必须包含：

- 文件名（`source_file_name`）
- 一句范围说明：**只删除本应用的记录与任务状态，不会动原始音视频文件**

按钮：`取消`（默认焦点）/ `删除`（危险色）。

### 实际删除什么（文件层面）

按 `job_id` 删除以下内容，**一律移入系统废纸篓**，禁止 `rm`：

| 路径 | 说明 |
| --- | --- |
| `transcripts/<job_id>.json` | 转写结果 |
| `jobs/<job_id>.json` | 任务状态 |
| `jobs/<job_id>.cancel` | 取消标记（存在才处理） |

**绝对不动**：

- `jobs/.dispatch.lock`（删了会破坏跨进程调度）
- 原始音视频文件
- `lan-host/` 下节点的任务（那是另一个任务体系）

### 边界

- 任务处于运行中 → 删除入口置灰，提示「请先取消该任务」
- 只有 transcript、没有 job（或反之）→ 能删多少删多少，报告实际删除了几项
- `job_id` 必须先通过已有的 `is_safe_job_id` 校验，防路径穿越
- 删除后：从内存 `state.transcripts` 移除；若当前正在阅读该条，回到首页
- 删除失败（权限/占用）→ 明确报错，不要假装修好

### 实现

- 新增 Tauri 命令 `delete_history_entry(job_id: String) -> Result<DeleteOutcome, String>`
- `DeleteOutcome { removed: Vec<String>, skipped: Vec<String> }`，前端据此提示
- 复用既有 `move_to_trash`（macOS）与 job store 的路径函数，**不要在组件里拼路径**

## 2. 模型页：去掉「已安装的模型」重复段

**现状**：页面上半部分是按分组列出的清单（准确优先 / 速度优先 / 辅助模型），下半部分又有一个「已安装的模型」列表。同一个模型在上下各出现一次，语义重复。

### 改法

1. **删除整个「已安装的模型」段**
2. 保留下面的分组结构：
   - 准确优先
   - 速度优先
   - 辅助模型（标点）——**保留**，理由见下
3. 每个模型的已安装状态、默认状态，继续显示在**清单条目本身**（`已下载` / `已安装，未加载` / `默认` / `设为默认` / `删除`），这些已有，不动
4. **兜底：非清单内的已安装模型**
   - 如果 `models/` 目录里存在清单里没有的模型（例如旧版本留下的、文件夹名为 id 的），删掉下面的列表后它们就无处可见
   - 因此：**仅当存在这类模型时**，在页面底部渲染一个「其它已安装」小节，只列这些，提供 `设为默认` 与 `删除`
   - 没有这类模型时，整个小节不出现（不能留一个空标题）

### 为什么保留「辅助模型」

标点模型（CT-Transformer）不是 ASR 主模型，塞进「准确优先」或「速度优先」都会误导。它是第三类，且有独立的下载/删除入口，删掉这一段等于让它无处可管。若确实要压成两块，需要另给标点模型一个入口——那是个更大的改动，本轮不做。

### 断言

- 页面上不再出现「已安装的模型」这个段标题
- 同一个模型名在页面中**只出现一次**（对已安装且已在清单中的模型做 DOM 计数）
- 三组标题仍在：准确优先、速度优先、辅助模型
- 「其它已安装」只在该类模型存在时出现

## 3. 测试

1. 右键卡片弹出菜单；`Esc` 关闭
2. 点击删除 → 出现确认；取消后文件仍在
3. 确认删除 → `transcripts/<id>.json`、`jobs/<id>.json`、`jobs/<id>.cancel`（若存在）进入废纸篓
4. 删除后 `jobs/.dispatch.lock` 仍存在
5. 删除后原始音视频文件仍在
6. 运行中的任务无法删除（入口禁用或命令返回可读错误）
7. `job_id` 为 `../x` 时被拒绝
8. 模型页：已安装模型在 DOM 中只出现一次；「已安装的模型」标题不存在
9. 「其它已安装」在小节无内容时不渲染
