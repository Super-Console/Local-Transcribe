## 1. 现状与两个错误

打开 `icons/tray-template@2x.png`（44×44）实际看到的是：**两个粗逗号**（像引号 `”`）。

| 错误 | 说明 |
| --- | --- |
| 形状 | 规格是**三条竖波**，实际是两个逗号形状 |
| 粗细 | 笔画约 4pt；macOS 菜单栏图标普遍 1.2–1.5pt，粗了近三倍 |

**第二条有一半是任务书的锅**：上一版写的是"宽 3px（22pt 画布）"，那等于 3pt 描边，本身就偏粗。这次按 1.5pt 重定。

---

## 2. 目标图形（按点计算，不是按像素拍脑袋）

画布 22×22 pt，内容 16×16 居中。

| 元素 | 值 |
| --- | --- |
| 竖条宽度 | **1.5 pt** |
| 竖条间距 | **3 pt**（条与条之间） |
| 高度（从左到右） | **6.5 / 11 / 8.5 pt** |
| 圆头半径 | 0.75 pt（即宽度的一半） |
| 垂直 | 三根都以中线对称：`y = 11` 为中心 |
| 水平 | 整组宽度 = 3×1.5 + 2×3 = **10.5 pt**，在 22 内水平居中（左起约 5.75） |
| 颜色 | 纯黑 `#000000`，alpha 255；背景全透明 |

**参照点**：macOS 菜单栏里的 SF Symbols 常用 1.2–1.5 pt 描边。1.5 已经是这条线上偏实的一档，**不要再加粗**。

**尺寸产出**

- `tray-template.png` — 22×22
- `tray-template@2x.png` — 44×44（按 2 倍：条宽 3px、间距 6px、高 13/22/17px）
- `tray-windows.png` — 32×32，**同一个形状**，白色 `#FFFFFF` + 透明底（Windows 不用 template）

## 3. 生成方式

- 继续用 `scripts/gen-tray-icon.py`（纯标准库 PNG + 4 倍超采样 + 幂等）
- 全部尺寸由同一份几何参数算出，不要手绘三份
- 生成后回读校验

## 4. 断言（这次要能抓出"形状错了"和"太粗"）

1. 三份文件存在，尺寸分别为 22 / 44 / 32，格式 RGBA
2. 四角 alpha = 0
3. **形状与粗细**：在 `tray-template@2x.png` 的 `y = 22`（中线）这一行水平扫描，
   - 黑色段**恰好 3 段**
   - 每段宽度 **3px（±1）**
   - 段与段之间的空隙 **6px（±1）**
   > 这条断言同时否掉"两个逗号"和"笔画过粗"两种错误
4. **面积上限**：整幅不透明像素占画布面积 **不超过 12%**（防止又画粗一圈）
5. `tray-windows.png` 的形状断言同上（只把颜色换成白），且主色 RGB ≥ 240
6. 重复运行脚本，产出字节一致
