# Local Transcribe — UI 视觉重设计任务书 V2.0

> 本次任务不是重新设计产品功能，而是对现有 UI 进行高质量的视觉重设计。
> 功能、页面结构与交互逻辑沿用已冻结的 V1.0 基线；本文件只覆盖视觉语言与设计图交付。

## 一、项目背景

Local Transcribe 是一款面向 macOS 和 Windows 的轻量级音视频转写应用，用户导入音频或视频文件，使用已导入的本地语音识别模型转写、阅读结果并导出 TXT / JSON。

既有 UI 的问题：像普通功能软件、缺少精致感、蓝色强调过多、侧栏与标题栏未融合、历史页/模型页像管理后台、卡片边框分隔线过多、八宫格总览图细节过小。

## 二、核心设计目标

**Apple 原生应用的优雅感 + Raycast 式专业工具的精致与高效。**

关键词：Native Desktop、Minimal、Refined、Calm、Premium、Lightweight、Content-first、Typography-driven。同时兼顾 Windows，保持同一套设计语言。

## 三、整体视觉语言

1. **配色**：中性色为主。浅色为柔和灰白背景、清晰不过分浓重的正文、更浅安静的侧栏、极淡分隔线、少量系统蓝；深色为深灰而非纯黑、舒适对比、避免高亮边框与发光。颜色必须有功能含义：蓝=主操作/焦点/选中/拖拽高亮，绿点=模型确实已加载到内存，红=错误或危险，灰=中性。不大面积使用蓝色。
2. **排版**：靠字体、字重、间距、留白建立层级；系统字体（macOS SF，Windows Segoe UI）；避免过大标题、过密文字、字号混乱、每区块独立卡片。
3. **圆角/阴影/边框**：适度圆角、非常轻微的阴影；避免玻璃拟态、过度透明、夸张渐变、大型悬浮卡片、厚重阴影、大量明显分隔线；层次优先用留白与背景微差。
4. **图标**：统一、细致、偏原生的线性图标，尺寸一致、线条协调；不用彩色拟物图标，不混用风格。

## 四、窗口与导航

双栏：左侧导航侧栏 + 右侧工作区。侧栏只有：转写、历史、模型，设置固定底部。不设常驻右侧信息面板。侧栏默认展开、可手动隐藏、窗口过窄自动隐藏。侧栏与标题栏自然融合（参考 Finder、Notes）。保留平台原生窗口控制（macOS 红黄绿、Windows 系统按钮），**不绘制假的 macOS 窗口控件**。默认窗口约 900×620 逻辑像素，需适应不同尺寸。

## 五、顶部工具栏

保持轻量：当前页面标题、侧栏显示/隐藏入口、存在任务时显示队列入口、默认语音识别模型选择器。模型选择器紧凑精致：名称表示新任务默认模型；绿点仅在该模型确实已加载时显示；已安装未加载为中性状态；支持搜索与键盘快速切换；更换默认模型不会立即加载模型。不在工具栏显示大量技术参数、内存占用或模型介绍。

## 六、转写主界面（最重要）

- **空闲态**：主内容充分留白；中央文件导入区：极细低对比虚线边框、简单文件图标、简短说明、精致的「选择文件」按钮；支持拖入；拖入时边框与背景轻微高亮；导入即创建任务，无须点「开始转写」；导入区不能像网站的大型上传组件，应自然融入桌面工作区。
- **进行中**：导入区让位给当前任务；显示文件名、实际模型、进度、取消、已稳定识别文字；正文逐段增长，界面不频繁跳动；用户上滚阅读时暂停自动跟随，需要时提供「查看最新」。
- **完成**：阅读式文本，按语义分段、不显示密集时间戳；只读、可选择、可复制、不内置编辑器；提供复制全文、导出 TXT、导出 JSON；像精致文本阅读器而非字幕编辑器。

## 七、队列浮层

非独立页面、非常驻侧栏；点顶部队列按钮显示轻量浮层。含当前执行任务、等待任务、拖拽手柄、任务模型、更换等待任务模型、移除等待任务、失败任务与重试。当前任务固定顶部不可拖动；等待任务可拖拽排序；失败任务不阻塞后续；取消后保留稳定文字并继续下一个。浮层精致紧凑，避免后台式表格与按钮堆。

## 八、历史页面

按日期分组紧凑列表（今天/昨天/更早）；每条显示文件名、时间、媒体时长、状态；支持搜索文件名与正文；状态含已完成/已取消/失败。点记录在历史页内看只读详情，返回保留搜索条件与列表位置；详情仍阅读式排版；整体像精致原生工具而非数据库管理系统，不用大型文件卡片。

## 九、模型页面

不提供在线商店与下载器；用户自行下载后导入。页面含已导入模型列表、导入模型按钮、模型详情、设默认模型、模型存储路径、删除模型。导入时验证格式与兼容性，成功后复制到应用专用目录并保留原始文件。详情可显示名称、支持语言、体积、实际或明确标注为估算的内存需求、运行状态、后端兼容性、来源与许可证。只有明确适配的模型可用。像轻量本地资源管理工具，不做商城/下载中心。

## 十、设置页面

分组：**通用**（主题跟随系统/浅色/深色、界面选项）；**转写**（默认模型、默认语言自动检测或选择支持语言、空闲卸载默认两分钟）；**存储**（模型目录、更改目录、打开目录、空间信息）；**集成**（CLI、MCP 状态与用法）；**关于**（名称、版本、开源与许可证）。不为设置而堆开关。

## 十一、必须覆盖的异常界面

尚未导入模型；已导入文件等待选择模型；模型格式不兼容；模型导入失败；媒体损坏；任务失败；用户取消；保留部分结果；转写中关闭窗口；异常退出后恢复队列；搜索无结果；模型目录不可用；窄窗自动折叠侧栏。文案简洁，不用夸张警告弹窗。

## 十二、交互与性能原则

响应迅速、空闲低占用、长文流畅、历史高效检索、队列不受页面切换影响、不重复加载模型、记住阅读位置、键盘快捷键、系统深浅色、无障碍与减少动态效果。模型、队列与后台状态必须来自统一核心，UI 不得伪造。

## 十三、设计图交付要求

不生成八宫格总览；按同一套视觉语言分别制作高质量设计图：

1. 主界面空闲状态（最重要，优先）
2. 转写进行中
3. 转写完成及阅读式结果
4. 队列浮层
5. 历史列表与历史详情
6. 模型管理及模型导入
7. 设置页面
8. 深色模式
9. 关键异常状态与确认对话框

所有页面保持一致：侧栏、工具栏、字体、图标、间距、圆角、色彩、控件形态。优先完整的单个应用窗口，不在单画面缩小展示大量窗口。

## 十四、明确禁止

SaaS 后台、大面积蓝色、大量卡片、大型渐变或夸张玻璃、无意义统计图、密集时间戳代替正文、未定义的 AI 总结/翻译/云端转写、在线模型商店、为视觉牺牲效率、改变已确定的信息架构。

## 十五、验收标准

呈现「安静、精致、轻量、真正为桌面设计」的语音转写工具；macOS 接近优秀原生应用完成度，Windows 遵循平台窗口规范并保持同一设计语言。靠排版、比例、留白、控件细节与一致性取胜，而不是装饰。

**先完成主界面空闲状态、建立设计语言，再一致扩展到其他页面。产品名统一为 Local Transcribe。**
