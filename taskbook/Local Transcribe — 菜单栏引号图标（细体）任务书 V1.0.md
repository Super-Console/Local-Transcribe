## 3. 目标几何（22pt 画布）

引号仍然是**实心字形**（菜单栏里的字形图标都是实心的，空心在 22pt 会发虚），但比例要收：

| 项 | 值 |
| --- | --- |
| 整组宽 | **8.5 pt**（22pt 画布的 38%） |
| 整组高 | **10.5 pt** |
| 单枚引号宽 | **3.5 pt** |
| 两枚间距 | **1.5 pt** |
| 竖笔最宽处 | **≤ 2 pt**（这是"细"的关键） |
| 尾部 | 圆头，收在下方约 2pt |
| 位置 | 22×22 画布内水平、垂直居中 |
| 颜色 | 纯黑 `#000000`，alpha 255；背景全透明 |

**对齐思路**：不要靠"整体缩小"来做细——整体缩会连带高度变矮、失去辨识度。要求的是**字形比例本身变瘦**：竖笔窄、两枚之间留白多、尾部收细。

**尺寸产出**

- `tray-template.png` — 22×22
- `tray-template@2x.png` — 44×44
- `tray-windows.png` — 32×32，同形状，白色 `#FFFFFF` + 透明底

## 5. 断言（这次的判据是"形对 + 够细"）

在 `tray-template@2x.png`（44×44）上：

1. **连通块恰好 2 个**（两枚引号）——否掉"三条竖条"和"粘成一坨"
2. **外接框**：宽 16–19px、高 20–22px（即 8–9.5pt × 10–11pt），居中（左右留白差 ≤1px）
3. **笔画宽度**：在字形上半部（外接框顶部往下 25% 处）水平扫描，每条连续黑色段宽度 **≤ 4px**（即 ≤2pt）
4. **面积占比**：alpha=255 的像素占画布 **3%–6%**
5. 四角 alpha = 0；`tray-windows.png` 主色 RGB ≥ 240，形状断言同上（颜色除外）
6. 三份文件尺寸 22 / 44 / 32，格式 RGBA；重复运行脚本字节一致
