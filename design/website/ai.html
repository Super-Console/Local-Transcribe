转写给你原文，AI 帮你提炼。总结、纪要、笔记、问答——用你自己的 API 地址、Key 和模型： BYOK（Bring Your Own Key），我们不提供、也不代管任何 AI 服务。

能力

转写结果页上的「AI」入口。

01

AI 总结

简短、标准、详细三档，适配「快速过一眼」到「归档备查」的不同需求。

02

会议纪要

议题、结论、待办分栏整理——不编造责任人与时间，原文没有的就不写。

03

课程笔记

按章节、知识点、重点概念组织，长课时录音也能变成可复习的笔记。

04

AI 问答

针对当前转写内容提问，优先依据原文回答；回答带段落引用，可回溯。

05

自定义提示词

创建、编辑、保存、复用你的处理模板——法学课一种模板，周会另一种。

长文本

数小时录音也接得住

按模型上下文容量与 Token 预算智能分段、分段处理、整合结果；带进度、可取消、失败可重试，尽量保留原文段落引用。

BYOK 配置

你的 Key，你的模型。

配置项说明
API Base URL支持自定义第三方中转地址
API Key存入系统安全存储（macOS 钥匙串 / Windows 凭据管理器 / iOS·Android Keystore），绝不明文入库
模型 Model ID任意 OpenAI-compatible 模型名
多配置切换保存多套 API 配置并快速切换，一键测试连接
协议优先支持 OpenAI-compatible Chat Completions，适配器架构可扩展其他协议

安全与边界

AI 请求，从你的设备直达你的服务商。

  • 仅在你主动使用 AI 功能时发送必要的转写文本；原始音视频永不上传。
  • 首次调用外部 AI 前明确告知：文本将发送到你配置的服务商。
  • API Key 不写入数据库、日志或 Git；不向局域网计算节点下发，请求默认由发起操作的设备执行。
  • 超时、取消、限流与有限重试，避免无限消耗 Token。
  • AI 结果单独保存，绝不覆盖原始识别文本；未配置 AI 服务时，离线转写功能完整可用。
  • 四端（macOS / Windows / iOS / Android）统一功能定义与结果数据结构。
