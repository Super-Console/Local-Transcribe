把重活，交给
家里的另一台电脑。

笔记本收音、台式机出稿。局域网计算（V1.1）把转写任务交给同一网络里的另一台电脑—— 文件只上传到你自己配对的节点，流量直连，没有云。

获取节点程序 安全边界

四步配对

从两台机器到一个节点。

  1. 在算力机上运行节点

    local-transcribe-node：指定监听地址、数据目录、模型目录，节点自动生成或由你指定配对令牌。

    local-transcribe-node --name gaming-pc --listen 0.0.0.0:7878 \
  --token <你的配对令牌> --compute on --role cpu \
  --model-dir /path/to/paraformer

  2. 在发送机上添加节点

    应用「局域网」视图：填名称、主机、端口、令牌；也可用 mDNS 自动发现（协议名 _localtranscribe._tcp）。

  3. 测试连接

    一眼看到节点是否在线、延迟多少、可用模型与角色、存储余量——每一项独立探测，令牌错误会明确显示，而不是含糊地「离线」。

  4. 发送与取回

    选择文件发送，分块上传支持断点续传；队列里看进度、可取消；完成后取回文字稿并归入本地历史。

安全边界

只连你配对过的机器。

认证

Bearer 令牌

节点的一切任务接口都要令牌；令牌只在配对时由你交换，不广播、不上传。

网络

局域网内直连

明文 HTTP 仅用于受信局域网；客户端流量一律直连节点，不经过系统代理（Clash 等代理环境下同样可用）。

范围

只传媒体文件

上传的只有你选择的媒体；模型不上传（节点用它自己的模型目录）；未来 AI 功能的 API Key 也不会下发到节点。

V1.1 为实验性功能、默认关闭。完整测试记录见仓库 docs/testing/windows-early-beta-test-report.md。
