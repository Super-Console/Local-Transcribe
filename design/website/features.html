功能一览

一套核心，三种用法。

桌面 GUI、命令行、本地 MCP 服务共享同一个应用核心：同一份设置、同一份历史、同一批模型。 你在哪里开始，就能在哪里继续。

已发布能力

Early Beta 里现在就能用的。

本地转写

文件进，文字稿出

Sherpa-onnx 推理引擎，支持 SenseVoice、Paraformer 等模型；CPU 运行，合适的 GPU 上可加速。模型由你导入、版本自己管，应用内可见驻留状态。

录音

录完即转

应用内麦克风录音，录完直接进入转写队列；应用音频内录（按应用捕获系统声音）为 macOS 专属能力。

结果管理

历史、搜索、导出

转写历史持久保存，全文搜索；导出纯文本；存储保留策略可配置，旧结果按策略自动清理。

三个界面

GUI / CLI / MCP

全局拖拽添加文件、自动识别格式；命令行适合批量与脚本；本地 stdio MCP 服务让 Agent 也能发起转写——三者地位平等，不厚此薄彼。

路线图

正在路上的。

以下为已立项、尚未发布的方向；以仓库任务书与实际发布为准。

Windows

精准应用录音 · 多音轨立项中

Windows 端按应用捕获音频（Application Loopback）与多音轨处理，向 macOS 的内录能力看齐。

移动端

iOS · Android立项中

手机端应用：现场录音 + 本地转写，与桌面端共享 LAN 任务协议，可把手机录音交给电脑转写。

AI

BYOK 内容处理立项中

总结、会议纪要、课程笔记、问答、自定义提示词——用你自己的 API 地址与 Key。详见 AI · BYOK。
