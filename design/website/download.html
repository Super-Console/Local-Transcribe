Early Beta，
装上就开始。

Windows 与 macOS 双平台早期测试版。无代码签名，欢迎系统提示属预期； 模型不随包提供，安装后在「模型」页导入即可。

macOS

1.1.0-beta.1 · Apple Silicon

  • 要求 macOS 13+（Apple Silicon）
  • 安装 .dmg 后首次启动：右键 → 打开（Gatekeeper 隔离提示，属预期）
Windows

1.1.0-beta.1 · x64 安装包

  • 要求 Windows 11 x64 + WebView2（通常随 Edge 已装）
  • SmartScreen 首次运行警告：「更多信息 → 仍要运行」

前往 GitHub Release 下载（发布后启用此链接）

Release 资产含：安装包、local-transcribe 命令行、local-transcribe-node 局域网节点程序、voice-to-text-service 本地服务，以及各资产 SHA256 校验值。

安装之后

还差一步：导入模型。

  1. 下载模型

    从 sherpa-onnx 模型库获取 SenseVoice 或 Paraformer 等模型，保持原始文件夹名。

  2. 导入

    应用「模型」页 → 导入，选择模型文件夹；应用校验模型结构并显示驻留状态。

  3. 转写

    拖入文件，或录音后转写。想把任务交给另一台电脑？见 局域网计算。
