# Local Transcribe — UI 设计图（V2.0）

按 `taskbook/Local-Transcribe-UI-V2.0-设计任务书.md` 产出。每张图是一个完整应用窗口（900 × 620 逻辑像素），
用纯 HTML/CSS 绘制，便于开发时逐项对照；**不包含任何假的 macOS 窗口按钮**，窗口左上角 38px 高度是原生控件的真实占位。

## 设计 token（浅色）

| 语义 | 值 | 用途 |
| --- | --- | --- |
| `--lt-bg` | `#FBFBFD` | 工作区背景 |
| `--lt-sidebar` | `#F1F1F4` | 侧栏（比工作区更安静） |
| `--lt-panel` | `#FFFFFF` | 需要凸起的控件（模型选择器、按钮） |
| `--lt-text` | `#1D1C1F` | 正文与标题 |
| `--lt-text-2` | `#6C6C72` | 次级信息 |
| `--lt-text-3` | `#9B9BA1` | 提示、占位 |
| `--lt-hairline` | `rgba(0,0,0,.075)` | 极淡分隔线 |
| `--lt-hairline-2` | `rgba(0,0,0,.12)` | 控件描边 |
| `--lt-accent` | `#0A7AFF` | 焦点、选中、拖拽高亮（少量） |
| `--lt-green` | `#34C759` | 模型已加载 |
| `--lt-red` | `#FF3B30` | 错误、删除、危险确认 |
| `--lt-fill` | `#ECECF0` / 悬停 `#E4E4E9` | 中性控件底色 |

工具栏控件高度 30–32px，按钮 30px，侧栏项 30px；圆角 7–12px（控件 8，面板 10–12）。
字号：页面标题 15/600，正文 15/1.7，辅助 12.5，提示 12；正文阅读列最大 720px，主内容水平内边距 28px。

深色模式在 `08-深色模式.html` 中给出同一套语义的深色取值（深灰 `#1C1C1E` 工作区，侧栏 `#232325`，正文 `#E9E9EC`）。

## 如何查看

- 直接打开 `index.html`：顶部页签切换 21 个完整窗口（每个都是 900×620 真实尺寸，窄窗 680×480）。
- 也可以单独打开各分组文件；`09-异常状态.html` / `05-历史.html` / `06-模型.html` 内含多屏与图注。
- `_build-designs.py` 是生成这些静态文件的脚本（共享同一套 token 与组件），修改基线后重新生成即可，不参与应用构建。
